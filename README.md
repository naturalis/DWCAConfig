# DWCAConfig
DWCA Configuratie bestanden om data te downloaden uit ES (NBA)

## Migration in progress

The NBA is undergoing an upgrade. As part of this upgrade, some inconsistencies with field names have changed (e.g. `altitudeUnifOfMeasurement` becomes `altitudeUnitOfMeasurement`, `sourceSystemId` becomes `sourceSystemID`). 

To accommodate these changes, the configuration files also need to be updated.
